# Schrift

`atkinson-hyperlegible-next-latin.woff2` ist die Schrift „Atkinson Hyperlegible Next“
des Braille Institute, entworfen für gute Lesbarkeit auch bei eingeschränktem Sehen.
Variable Schrift, Gewichte 200 bis 800, lateinischer Zeichensatz.

- Lizenz: SIL Open Font License 1.1, <https://openfontlicense.org>
- Quelle: Google Fonts, <https://fonts.google.com/specimen/Atkinson+Hyperlegible+Next>

Die Datei liegt im Theme, damit die Seite nichts von fremden Servern lädt.
